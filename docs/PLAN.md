# fysio-work-sdk — plan (draft)

> Draft bootstrapped by cardmem Init (Branch C), 27 Nov 2026. For the owner to review before merge.

## Purpose

`@fysio-work/sdk` is the kit every module on **fysio.work** is built with — our own modules, partners' and third parties'. It ships the platform contracts as machine-readable specs and a thin runtime (`createModule`) that sets up ticket checks, organization context, allowlist logging, GDPR endpoints, widgets, health and graceful shutdown. Published to npm from this public repo via OIDC with provenance.

## Current stack

TypeScript (ESM), Hono, Zod, tsup, Vitest + a mutation guard (`test/mutations.mjs`). Specs in OpenAPI 3.1, AsyncAPI 3 and JSON Schema; TS generated by `scripts/generate.mjs`.
